# site-web-selarl-julie-samama-v2

Prototype multi-pages statique de la SELARL Julie Samama, préparé pour une prévisualisation simple sur Netlify.

## Structure

- Accueil
- Services
  - Médecine préventive
  - Médecine générale
  - Pathologies locomotrices
  - Dentisterie équine
  - Médecine respiratoire
  - Chirurgie de terrain
- Équipements
- Tarifs
- Blog
  - Conseils & prévention
  - Veille scientifique
- À propos
- Zone d’intervention
- Contact
- Demander un rendez-vous
- Urgences

## Déploiement Netlify

Aucune étape de build n’est nécessaire.

- Publish directory: `.`
- Build command: vide

Un `netlify.toml` est inclus.

## Gouvernance

- Les tarifs et forfaits restent non publiés tant qu’ils ne sont pas validés.
- Les modalités détaillées d’urgence restent à valider.
- Les contenus médicaux sensibles doivent être validés avant publication.
- Le formulaire de rendez-vous n’est pas activé dans cette première base afin d’éviter toute collecte de données personnelles non validée.
- Le logo officiel et les photographies autorisées restent à intégrer.
